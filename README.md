# Walmart Sales Forecast

Projeto de previsão de vendas utilizando Python e técnicas de séries temporais.

## Objetivo

Desenvolver modelos capazes de prever as vendas futuras das lojas Walmart e gerar insights para apoiar decisões estratégicas.

## Tecnologias

- Python
- Pandas
- Matplotlib
- Seaborn
- Statsmodels
- Prophet
